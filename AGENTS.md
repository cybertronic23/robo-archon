# Repository instructions

## Demonstration media

- Do not commit MP4, MOV, or WebM recordings. Keep full videos in ignored local output directories or CI artifacts.
- When a public animation is useful, commit a compact GIF preview and link it from the documentation.
- GIFs can be larger than MP4. Reduce resolution, frame rate, duration, and palette; inspect the result and check its actual size. Aim for no more than 1 MiB per new preview.
- Do not use `git add -f` to bypass video ignore rules.
- Do not rewrite published Git history to remove old videos without an explicit user request.
